如何使用：
---------

1. 从其他 Activity 跳转到用户资料页面：

   Intent intent = new Intent(this, UserProfileActivity.class);
   startActivity(intent);

2. 在登录成功后跳转：

   // 在 LoginActivity 或 MainActivity 中
   if (loginSuccess) {
       Intent intent = new Intent(this, UserProfileActivity.class);
       startActivity(intent);
   }

界面特性：
---------

1. 背景颜色：#FDF7FA（淡粉色）
2. 圆形头像：80dp x 80dp，带阴影
3. 白色容器：圆角顶部设计
4. 标签切换：流畅的视觉反馈
5. 响应式布局：适配不同屏幕尺寸
6. 空状态处理：没有内容时显示提示

注意事项：
---------

1. 需要在 Gradle 同步后才能使用
2. 头像和作品缩略图需要配合图片加载库（如 Glide）
3. 数据加载需要连接后端 API
4. 建议添加下拉刷新和上拉加载更多功能
