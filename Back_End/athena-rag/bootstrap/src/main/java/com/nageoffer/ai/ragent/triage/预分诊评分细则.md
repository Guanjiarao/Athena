# 预分诊系统 — 双轨评分细则

> **结果评分** 100分：已有评测集标准答案，6维度评分
> **过程评分** 100分：独立评估问诊过程质量，5维度评分
> 最终总评可分别统计，也可按需加权合并

---

## 一、结果评分（100分）

沿用现有评测集格式，每个用例6个维度：

| 维度 | 分值 | 说明 |
|------|:---:|------|
| 风险等级 | 20 | 🟢/🟡/🔴 判定是否正确 |
| 建议科室 | 15 | 建议科室与标准答案是否一致 |
| 主诉提炼 | 15 | 主诉是否清晰准确概括核心问题 |
| 症状提取 | 20 | 从对话中提取的关键症状是否完整 |
| 风险分析 | 15 | 风险分析是否合理（有无高危体征判断） |
| 行动建议 | 15 | 建议是否具体、可执行 |
| **总分** | **100** | |

---

## 二、过程评分（100分）

### 2.1 幻觉/记忆一致性（30分）⚠️ 权重最高

**定义：** 系统是否记得用户已经回答过的信息，是否会重复提问相同问题。

| 分值 | 标准 |
|:---:|------|
| 26-30 | **无幻觉**：全程无重复提问，每轮追问都基于新信息推进 |
| 16-25 | **轻微幻觉**：有1次重复提问，或在尾声冗余确认已说过的信息 |
| 6-15 | **中等幻觉**：2-3次重复提问，明显不记得用户已回答内容 |
| 0-5 | **严重幻觉**：多次重复提问（≥4次），或关键信息丢失导致回到已问过的问题 |

**典型扣分场景：**
- 用户回答"37.5°C"后，又在一轮后问"有没有发烧？" → 扣分
- 用户说"肚脐周围疼"，后面又问"疼在哪个位置" → 扣分
- 用户说"有高血压"，后面又问"以前有高血压吗" → 扣分

---

### 2.2 信息完整度（20分）

**定义：** 问诊是否覆盖了对分诊决策有决定意义的全部关键信息。

| 分值 | 标准 |
|:---:|------|
| 17-20 | **完整**：覆盖全部关键鉴别诊断维度，不遗漏必问信息 |
| 11-16 | **基本完整**：覆盖大部分维度，缺失1个非核心信息 |
| 6-10 | **部分缺失**：缺少1-2个对分诊较关键的信息 |
| 0-5 | **严重缺失**：缺少核心鉴别信息，可能导致分诊结论偏差 |

**必问判断参考：**
- 腹泻用例：病程+次数+性状+发热+腹痛+诱因+呕吐（7维）
- 胸痛用例：病程+性质+位置+放射+冷汗+年龄+病史（7维）
- 外伤用例：时间+部位+深度+出血量+止血+抗凝药（6维）

**评分方法：** 对照测试集中**标准对话**的信息量。

---

### 2.3 对话轮次合理性（15分）

**定义：** 追问轮次是否适中。

| 分值 | 标准 |
|:---:|------|
| 13-15 | **合理**：7-8轮追问，信息量刚好支撑分诊决策 |
| 9-12 | **可接受**：5-6轮或9-10轮，信息略有不足或略有冗余 |
| 5-8 | **偏少/偏多**：≤4轮（漏信息）或≥11轮（冗余） |
| 0-4 | **严重不合理**：≤2轮基本没问或≥15轮拖沓 |

**基准参考：**
- 常见症状（腹泻、头痛、咳嗽）：6-8轮
- 复杂症状（胸痛、腹痛鉴别）：7-10轮
- 紧急情况（心梗、脑卒中）：3-5轮即触发告警（轮次少不扣分，因合理）
- 极简单情况（体检异常咨询）：4-6轮

---

### 2.4 逻辑连贯性（15分）

**定义：** 追问顺序是否符合从主诉→鉴别诊断的临床推理逻辑。

| 分值 | 标准 |
|:---:|------|
| 13-15 | **优秀**：逻辑递进清晰，先问"是什么"→"什么感觉"→"多久了"→"伴随什么"→"为什么"，完全符合临床思维 |
| 9-12 | **良好**：基本符合逻辑顺序，偶有1-2处顺序可优化 |
| 5-8 | **一般**：逻辑顺序有较明显问题，或跳跃感强 |
| 0-4 | **差**：逻辑混乱，问题之间无关联，或关键鉴别问题放在了最后 |

**推荐顺序：**
```
主诉 → 部位 → 时间/病程 → 性质 → 程度 → 诱因 → 伴随症状 → 危险因素 → 既往史
```

**特别说明（急症例外）：**
- 如果用户说"胸口疼，喘不上气"，应该**优先问**"疼多久了"+"往哪放射"+"出冷汗吗"，而不是先问"几岁"+"吃药了吗"
- 在紧急场景中，把关键鉴别问题前置不算逻辑混乱，而是合理的临床优先级

---

### 2.5 选项推送率（20分）

**定义：** 每轮追问是否都推送了合理的候选选项，且包含"其他"兜底。

| 分值 | 标准 |
|:---:|------|
| 17-20 | **优秀**：每轮都推送选项，选项覆盖主要答案分支且措辞合理，均含"其他"兜底 |
| 11-16 | **良好**：绝大多数轮次推送选项，偶有1-2轮漏推，选项基本合理 |
| 6-10 | **一般**：部分轮次未推送选项，或选项设计有缺陷（选项不全/不符） |
| 0-5 | **差**：很少推送选项，或完全没有选项推送机制 |

**选项设计扣分项：**
- 选项中没有"其他"兜底选项 → 每缺一轮扣2分
- 选项与问题不匹配 → 每次扣3分
- 选项遗漏常见分支 → 每次扣2分
- 所有选项都不符合用户情况（用户只能选"其他"）→ 该轮选项设计不合理扣3分
- 连续3轮以上没有选项推送 → 额外扣5分

## 三、评分流程

```
┌─────────────────────────────────────────────────────┐
│  读测试用例 → 获取 输入(用户主诉) + 标准对话 + 标准答案 │
├─────────────────────────────────────────────────────┤
│                                                       │
│  → 让被评测系统回答（或使用已录制的回答）              │
│                                                       │
│  → 结果评分（对照标准答案逐项打分）                    │
│    风险等级__/20 + 科室__/15 + 主诉__/15              │
│   + 症状__/20 + 风险分析__/15 + 建议__/15 = __/100   │
│                                                       │
│  → 过程评分（对照标准对话逐项打分）                    │
│    幻觉/记忆__/30 + 信息完整__/20 + 轮次__/15        │
│   + 逻辑__/15 + 选项__/20 = __/100                    │
│                                                       │
│  → 输出：结果分 + 过程分 + 扣分原因                   │
│                                                       │
├─────────────────────────────────────────────────────┤
│  汇总100个测试集 → 平均分 + 各维度缺陷分布 + 系统分类分析 │
└─────────────────────────────────────────────────────┘
```

---

## 四、两种使用方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| **双轨制** | 过程分和结果分独立计算，两份报告并列 | 研发迭代阶段，需分别优化过程和结果 |
| **合并制** | 过程×0.7 + 结果×0.3 = 总分100 | 最终排名，综合评价系统能力 |

**建议：** 先用双轨制跑几轮，等系统稳定后再用合并制出最终总分。
