> 共100个测试用例，覆盖20个医疗系统

## 用例001：急性肠胃炎（轻症 🟢）

**系统分类**：预分诊测试用例 — 消化系统

**输入**：
```
拉肚子，肚子咕噜咕噜叫
```

**标准对话**：
```
系统：拉肚子从什么时候开始的？
用户：今天开始的
系统：一天拉了几次？
用户：3次
系统：大便是什么样的？
用户：水样
系统：有发烧吗？
用户：没有
系统：肚子哪个位置疼？
用户：肚脐周围
系统：最近吃了不干净的东西吗？
用户：路边摊
系统：有恶心呕吐吗？
用户：有点恶心
```

**评分标准**：

| 维度 | 标准答案 | 分值 |
|------|---------|:----:|
| 风险等级 | 低风险 🟢 | 20 |
| 建议科室 | 消化内科 | 15 |
| 主诉提炼 | 拉肚子，肚子咕噜咕噜叫 | 15 |
| 症状提取 | 腹泻/大便：今天开始的，腹泻/大便：3次，腹泻/大便：水样，发热：没有，疼痛：肚脐周围，诱因：路边摊 | 20 |
| 风险分析 | 症状轻微，无高危体征，可居家观察或择期就诊 | 15 |
| 行动建议 | 建议择期门诊就诊；注意休息观察；如加重及时就医 | 15 |

**总分**：100
