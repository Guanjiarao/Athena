# 教学对话纪要：Session 01

## 会话背景

用户希望基于 `ragent/ragentlearn.md` 开展系统教学，目标不是继续学习基础 RAG 理论，而是围绕真实项目建立实战理解。

## 已完成内容

### 1. 明确教学目标

用户说明：

- `ragentlearn.md` 是围绕 `ragent` 项目整理出的教学大纲
- 接下来需要基于该大纲开展持续教学
- 用户已经掌握基础 RAG 理论，但缺少项目实战经验

因此后续教学重心从“概念扫盲”调整为：

- 项目架构拆解
- 主链路源码带读
- 工程设计取舍
- 如何从真实项目中提炼可复用经验

### 2. 已整理出的阶段性教学内容

#### 第 1 课
主题：RAG 全景图——从理论到工程

核心内容：

- RAG 的工程链路概览
- 纯 LLM 与 RAG 的工程差异
- `ragent` 在整条链路中的平台定位

#### 第 2 课
主题：`ragent` 项目架构总览

核心内容：

- 四大模块职责拆分：`bootstrap`、`framework`、`infra-ai`、`mcp-server`
- 为什么真实项目必须做模块边界拆分
- 第一次阅读项目时的推荐顺序

### 3. 用户反馈与教学策略调整

用户反馈认为：

- 基础理论部分不需要再展开
- 希望教学内容更专业、更贴近真实项目阅读与实践

基于该反馈，后续教学策略调整为：

1. 不再重复普适 RAG 理论
2. 以 `ragent` 项目源码为中心展开
3. 每节课优先回答“真实工程里这个问题怎么解决”
4. 尽量围绕调用链、配置、模块职责、设计取舍来讲

## 后续教学计划

下一步建议进入：

- 读取并分析 `bootstrap/application.yaml`
- 从配置反推整个系统能力边界
- 再顺着问答链路逐步进入源码

## 本目录维护约定

后续每次有阶段性教学进展，可继续新增新的 Session 文件，例如：

- `session-02.md`
- `session-03.md`

用于记录：

- 本轮讲了什么
- 用户反馈了什么
- 教学策略如何调整
- 下一步准备读哪些源码
