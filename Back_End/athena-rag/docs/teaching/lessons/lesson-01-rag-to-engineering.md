# 第 1 课：RAG 全景图——从理论到工程

## 本课定位

本课用于建立 `ragent` 项目的总认知，不重复展开基础 RAG 理论，而是把重点放在：

- RAG 在工程里的完整链路是什么
- 为什么企业项目不能只依赖纯 LLM
- `ragent` 在整条链路中的定位是什么

## 本课核心结论

### 1. RAG 的本质

RAG 不是让模型直接回答问题，而是：

1. 先从外部知识源中检索相关信息
2. 再基于检索结果生成答案

因此，RAG 解决的核心问题是：

- 私域知识接入
- 实时知识更新
- 降低幻觉
- 提高答案可追溯性

### 2. 一个完整 RAG 系统的工程链路

完整链路通常包括：

1. 文档输入
2. 文档解析
3. 文本分块
4. Embedding 向量化
5. 向量与 metadata 存储
6. 用户提问
7. 查询改写 / 上下文补全
8. 检索 topK 相关片段
9. 去重 / 重排序 / 多路融合
10. Prompt 组装
11. LLM 生成答案
12. 返回答案与引用

### 3. `ragent` 的项目定位

`ragent` 不是一个简单 Demo，而是一个工程化的 RAG 平台，覆盖：

- 文档入库
- 多通道检索
- 意图识别
- Prompt 编排
- 会话记忆
- 模型路由
- MCP 工具调用
- Trace 链路追踪

## 学习建议

这节课只要求建立整体地图，不要求记住全部细节。

后续学习方式应遵循：

- 先理解整条链路
- 再拆分具体模块
- 最后结合源码走通主流程
