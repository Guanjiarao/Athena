# 分诊台架构文档

当前分诊链路以仓库根目录的 `docs/triage-multi-agent-architecture.md` 为准。

本目录只保留仍有参考价值的代码说明文档；已删除旧 `v2` 重构方案和源码目录下的 `原架构` 文档，避免和当前多 Agent 架构混淆。

## 当前主架构

```text
Normalization Agent
  -> parallel Risk / Rule / Slot Agents
  -> Context Reducer
  -> Question Planner
  -> Response Agent
```

- `01-总体架构.md`：当前代码里的真实分层与主链路
