# 分诊台架构文档（代码驱动版）

这组文档基于当前代码重新整理，旧的重构计划只作为背景材料，不直接当现状。

## 说明

每份文档尽量按三类标注：
- `已确认`：已从当前代码直接读到并确认
- `待验证`：当前还没读全或边界还需继续确认
- `历史文档推测，暂不采信`：旧计划里可能成立，但不作为当前事实

## 文档结构

- `01-总体架构.md`：当前代码里的真实分层与主链路
- `02-核心数据与状态.md`：核心对象、状态流转、读写边界
- `03-执行链路与模块职责.md`：按代码链路拆开模块职责
- `04-架构图.md`：文本架构图与数据流图
- `05-模块职责图.md`：按类展开的职责、输入、输出、禁区
- `06-待验证清单.md`：当前仍需复核的边界

## 阅读顺序

1. `01-总体架构.md`
2. `02-核心数据与状态.md`
3. `03-执行链路与模块职责.md`
