# 经期管理


## 记录经期开始


**接口地址**:`/athena/menstruation/start`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>记录经期开始时间</p>



**请求示例**:


```javascript
{
  "startDate": ""
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|menstruationStartDTO|MenstruationStartDTO|body|true|MenstruationStartDTO|MenstruationStartDTO|
|&emsp;&emsp;startDate|||false|string(date)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|ResultMenstruationCycleVO|


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code||integer(int32)|integer(int32)|
|message||string||
|data||MenstruationCycleVO|MenstruationCycleVO|
|&emsp;&emsp;id||integer(int64)||
|&emsp;&emsp;startDate||string(date)||
|&emsp;&emsp;endDate||string(date)||
|&emsp;&emsp;displayEndDate||string(date)||
|&emsp;&emsp;durationDays||integer(int32)||
|&emsp;&emsp;displayDurationDays||integer(int32)||
|&emsp;&emsp;cycleLength||integer(int32)||
|&emsp;&emsp;predicted||boolean||
|&emsp;&emsp;monthStartDate||string(date)||
|&emsp;&emsp;monthEndDate||string(date)||
|total||integer(int64)|integer(int64)|


**响应示例**:
```javascript
{
	"code": 0,
	"message": "",
	"data": {
		"id": 0,
		"startDate": "",
		"endDate": "",
		"displayEndDate": "",
		"durationDays": 0,
		"displayDurationDays": 0,
		"cycleLength": 0,
		"predicted": true,
		"monthStartDate": "",
		"monthEndDate": ""
	},
	"total": 0
}
```
