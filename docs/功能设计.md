# 功能设计

本文档描述 Athena 双端系统的功能结构、模块划分和主要交互逻辑。

## 1. 总体架构

系统由两个前端组成：

- Web 管理端：负责内容审核、内容管理和发布协同
- Android App：负责用户侧内容消费、记录管理和 AI 辅助服务

二者通过后端接口和内容流程联动。

## 2. 网站前端功能设计

### 2.1 登录与权限控制

Web 端采用角色控制：

- 未登录用户只能访问登录页
- `admin` 登录后进入审核和内容管理流程
- `kol` 登录后进入内容发布流程

### 2.2 内容审核

审核模块主要职责：

- 拉取待审内容列表
- 查看内容详情
- 展示封面、正文、视频等信息
- 执行删除或状态处理

### 2.3 内容管理

内容管理模块用于管理已发布或待管理的内容，支持：

- 按模块分类
- 按类型过滤
- 查看内容明细
- 删除内容

### 2.4 内容发布

发布模块提供文章和视频两类入口：

- 文章发布
- 视频发布

发布完成后进入后台审核或管理流程。

### 2.5 系统设置

系统设置模块用于保留扩展能力，例如账号相关设置、配置查看和后续功能扩展。

## 3. App 功能设计

### 3.1 主导航设计

App 使用底部导航组织核心能力：

- 知识
- 广场
- AI
- 记录
- 我的

### 3.2 知识内容模块

知识模块按用户生命周期和主题分类展示健康知识。

主要分类：

- 0 到 12 岁
- 12 到 22 岁
- 成熟阶段
- 55+
- 月经
- 备孕
- 避孕
- 亲子
- 皮肤护理
- 性健康

### 3.3 社区广场模块

广场模块提供图文和视频内容流，包含：

- 内容列表
- 内容详情
- 评论
- 点赞和互动
- 发布入口

### 3.4 AI 模块

AI 模块用于智能问答和辅助分析，包含：

- 对话输入
- 历史会话
- 参考内容回溯
- 结合知识内容的检索式回答

### 3.5 记录与监测模块

记录模块支持：

- 周期记录
- 排卵期相关提醒
- 生理状态记录
- 健康监测数据管理

### 3.6 隐私与安全模块

隐私模块用于处理敏感健康图像和报告，包含：

- 本地脱敏
- 图片遮挡或模糊
- OCR 识别
- 安全上传与 AI 分析

### 3.7 个人中心模块

个人中心用于管理用户资料、关注关系、私密内容和设置项。

## 4. 数据流设计

### 4.1 Web 端流程

1. 用户登录获取 token。
2. token 写入本地存储。
3. 请求时自动附带鉴权头。
4. 根据角色进入对应页面。

### 4.2 App 端流程

1. 用户登录后生成本地凭证。
2. App 根据登录状态显示底部导航。
3. 各模块通过接口或本地缓存读取数据。
4. 图片、视频、文本和健康数据按对应模块展示。

## 5. 关键技术点

- Web 端路由保护
- Web 端角色分流
- App 端底部导航与 Fragment 切换
- App 端多权限支持
- 图片上传与视频播放
- OCR 与 AI 接入
- 健康数据分析与周期计算



## 4. RAG 前端功能设计

### 4.1 用户端功能

**智能对话**：
- 发送文本消息（1-2000 字符）
- 实时流式响应（SSE）
- Markdown 渲染、代码高亮
- 深度思考模式（AI 先思考再回答）
- 消息操作：复制、点赞/点踩、停止生成
- 引用来源展示

**会话管理**：
- 新建对话
- 切换会话
- 重命名会话（1-50 字符）
- 删除会话（需确认）
- 会话列表（按时间排序）

### 4.2 管理端功能

**仪表板**：
- 知识库数量、文档数、会话数统计
- 查询量趋势图

**知识库管理**：
- 创建知识库（名称、描述、嵌入模型）
- 上传文档（PDF/DOCX/TXT/MD/HTML）
- 查看文档列表
- 查看文档分块（chunks）
- 删除知识库/文档

**数据摄取**：
- 批量上传文档
- 配置切分参数（chunk_size: 256-2048, overlap: 0-200）
- 查看处理进度

**意图管理**：
- 意图树展示（树形结构）
- 意图列表（表格管理）
- 新建/编辑意图（名称、父意图、触发关键词、响应策略）
- 删除意图

**链路追踪**：
- 查看 RAG 调用记录（筛选、搜索）
- 追踪详情（查询、检索结果、生成信息、性能统计）

**系统设置**：
- LLM 配置（模型、温度、Token 数）
- 向量模型配置
- 检索参数（Top K、相似度阈值）

**用户管理**：
- 用户列表
- 新建用户（用户名 3-20、密码 6-128、角色）
- 修改角色（user/admin）

**其他**：
- 示例问题管理
- 关键词映射（同义词转换）

### 4.3 权限控制

- `user`：只能访问聊天功能
- `admin`：可访问所有功能
- 非管理员访问 `/admin/*` 自动跳转 `/chat`
