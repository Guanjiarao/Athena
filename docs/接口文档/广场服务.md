# 广场管理


## 记录浏览


**接口地址**:`/athena/blog/view`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded`


**响应数据类型**:`*/*`


**接口描述**:<p>记录笔记浏览（用户停留 ≥ 3 秒后前端调用）</p>



**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|noteId|笔记ID|query|true|integer(int64)||
|duration|停留时长（秒）|query|false|integer(int32)||


**响应状态**:


| 状态码 | 说明 | schema |
| -------- | -------- | ----- | 
|200|OK|Result|


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |
| -------- | -------- | ----- |----- | 
|code||integer(int32)|integer(int32)|
|message||string||
|data||object||
|total||integer(int64)|integer(int64)|


**响应示例**:
```javascript
{
	"code": 0,
	"message": "",
	"data": {},
	"total": 0
}
```


## 上传笔记


**接口地址**:`/athena/blog/submit`


**请求方式**:`POST`


**请求数据类型**:`application/x-www-form-urlencoded,application/json`


**响应数据类型**:`*/*`


**接口描述**:<p>用户上传新笔记</p>



**请求示例**:


```javascript
{
  "userId": 0,
  "title": "",
  "topicId": 0,
  "topicName": "",
  "isTop": true,
  "type": "",
  "coverUrl": "",
  "imgUrls": [],
  "videoUrl": "",
  "visible": "",
  "content": "",
  "channelId": 0,
  "channelName": ""
}
```


**请求参数**:


| 参数名称 | 参数说明 | 请求类型    | 是否必须 | 数据类型 | schema |
| -------- | -------- | ----- | -------- | -------- | ------ |
|noteSubmitDTO|上传笔记请求DTO|body|true|NoteSubmitDTO|NoteSubmitDTO|
|&emsp;&emsp;userId|用户ID||true|integer(int64)||
|&emsp;&emsp;title|标题||true|string||
|&emsp;&emsp;topicId|话题ID||false|integer(int64)||
|&emsp;&emsp;topicName|话题名称||false|string||
|&emsp;&emsp;isTop|是否置顶||false|boolean||
|&emsp;&emsp;type|笔记类型（1-图文，2-视频等）||true|string(byte)||
|&emsp;&emsp;coverUrl|封面URL||false|string||
|&emsp;&emsp;imgUrls|图片URL列表||false|array|string|
|&emsp;&emsp;videoUrl|视频URL||false|string||
|&emsp;&emsp;visible|可见性（1-公开，2-仅自己可见）||true|string(byte)||
|&emsp;&emsp;content|文本||false|string||
|&emsp;&emsp;channelId|频道ID||false|integer(int32)||
|&emsp;&emsp;channelName|频道名称||false|string||


**响应状态**:


| 状态码 | 说明 | schema |

|200|OK|ResultLong|


**响应参数**:


| 参数名称 | 参数说明 | 类型 | schema |

|code||integer(int32)|integer(int32)|
|message||string||
|data||integer(int64)|integer(int64)|
|total||integer(int64)|integer(int64)|
