# 安装维护

本文档说明 Athena 双端项目的安装方式、运行准备和日常维护建议。

## 1. 环境要求

### 1.1 网站前端

- Node.js 18 或更高版本
- npm
- 推荐使用 Chrome 或 Edge 浏览器

### 1.2 Android App

- Android Studio
- JDK 8 或兼容版本
- Android SDK
- 支持 Android 7.0 及以上的测试设备或模拟器

## 2. 网站前端安装

### 2.1 安装依赖

```bash
cd admin_web_front
npm install
```

### 2.2 启动开发环境

```bash
npm run dev
```

### 2.3 构建生产包

```bash
npm run build
```

### 2.4 预览构建结果

```bash
npm run preview
```

## 3. Android App 安装

### 3.1 导入项目

1. 使用 Android Studio 打开 `athena_app_front`。
2. 等待 Gradle 同步完成。
3. 确认 `app` 模块可正常编译。

### 3.2 运行方式

1. 选择连接的真机或模拟器。
2. 点击运行 `app` 模块。
3. 首次启动时按提示授予权限。

### 3.3 打包建议

- 调试包用于联调和测试。
- 发布包建议单独配置签名和混淆策略。

## 4. 配置维护

### 4.1 Web 端

重点检查以下内容：

- 接口地址是否与后端一致
- 登录态 token 是否正常保存
- 管理员和发布者角色是否正确区分
- 生产环境是否开启正确的构建模式

### 4.2 App 端

重点检查以下内容：

- `AndroidManifest.xml` 中权限是否齐全
- 网络请求配置是否正确
- 登录 token 是否能正常持久化
- 图片、视频、OCR、AI 相关依赖是否可用

## 5. 数据与日志维护

- Web 端登录态默认保存在浏览器本地存储中。
- App 端登录态保存在本地 `SharedPreferences` 或相关存储中。
- 调试时重点查看：
  - Web 浏览器控制台日志
  - Android Studio Logcat

## 6. 常见维护操作

### 6.1 更新接口

后端接口变更后，优先检查：

- 请求路径
- 请求参数结构
- 返回码和错误字段
- 鉴权方式

### 6.2 修复页面问题

推荐流程：

1. 先定位页面或 Activity/Fragment。
2. 检查数据请求是否成功。
3. 再排查样式、空值和权限问题。
4. 最后补充回归测试。

### 6.3 新增功能

新增功能时建议同步更新：

- 页面入口
- 路由或导航
- 接口定义
- 文档说明

## 7. 维护注意事项

- 不要直接修改生产环境配置而不留备份。
- 不要在未确认接口兼容性前发布客户端。
- 涉及隐私、健康、分析数据的功能，建议保留最小必要日志。
- 依赖升级后要做完整回归测试，尤其是登录、上传、播放和 AI 相关能力。



## 7. RAG 前端安装

### 7.1 环境要求

- Node.js >= 16.x（推荐 18.x）
- npm >= 8.x
- 浏览器：Chrome 90+ / Firefox 88+ / Safari 14+

### 7.2 开发环境

**安装依赖**：
```bash
cd athena_rag_front/rag-frontend/frontend
npm install
```

**配置环境变量** (`.env`):
```env
VITE_API_BASE_URL=/api/ragent
VITE_APP_NAME=Athena RAG
```

**启动开发服务器**：
```bash
npm run dev  # http://localhost:5173
```

**注意**：确保后端运行在 9090 端口

### 7.3 生产部署

**构建**：
```bash
npm run build  # 输出到 dist/
```

**Nginx 配置**：
```nginx
server {
    listen 80;
    root /var/www/athena-rag-frontend;
    
    # SPA 路由
    location / {
        try_files \ \/ /index.html;
    }
    
    # API 代理
    location /api/ragent {
        proxy_pass http://localhost:9090;
        proxy_http_version 1.1;
        proxy_set_header Upgrade \;
        proxy_set_header Connection 'upgrade';
        proxy_read_timeout 300s;  # SSE 需要长连接
    }
}
```

**启用配置**：
```bash
sudo ln -s /etc/nginx/sites-available/athena-rag /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

### 7.4 故障排查

**问题 1：npm install 失败**
```bash
npm cache clean --force
npm install --registry=https://registry.npmmirror.com
```

**问题 2：API 404**
- 检查后端是否运行在 9090 端口
- 检查 Vite 代理配置

**问题 3：白屏或刷新 404**
- 确保 Nginx 配置了 SPA 路由：`try_files \ \/ /index.html;`

**问题 4：SSE 连接中断**
- 增加 Nginx 超时：`proxy_read_timeout 300s;`
