# Athena RAG Frontend 需求规格

> 版本：v1.0  
> 更新时间：2026-06-10

---

## 1. 功能需求

### FR-1 用户认证

- FR-1.1 用户登录（用户名 + 密码）
- FR-1.2 Token 自动登录
- FR-1.3 退出登录
- FR-1.4 401 自动跳转登录

### FR-2 智能对话

- FR-2.1 发送文本消息（1-2000 字符）
- FR-2.2 实时流式响应（SSE）
- FR-2.3 深度思考模式
- FR-2.4 停止生成
- FR-2.5 消息反馈（点赞/点踩）
- FR-2.6 引用来源展示

### FR-3 会话管理

- FR-3.1 获取会话列表
- FR-3.2 创建新会话
- FR-3.3 切换会话
- FR-3.4 重命名会话（1-50 字符）
- FR-3.5 删除会话（需确认）

### FR-4 知识库管理

- FR-4.1 创建知识库（名称、描述、模型）
- FR-4.2 查看知识库列表
- FR-4.3 删除知识库（需确认）
- FR-4.4 上传文档（PDF/DOCX/TXT/MD/HTML, < 50MB）
- FR-4.5 查看文档列表
- FR-4.6 删除文档
- FR-4.7 查看文档分块

### FR-5 数据摄取

- FR-5.1 批量上传文档
- FR-5.2 配置参数（chunk_size: 256-2048, overlap: 0-200）
- FR-5.3 显示上传进度

### FR-6 意图管理

- FR-6.1 意图树展示
- FR-6.2 意图列表管理
- FR-6.3 新建/编辑意图
- FR-6.4 删除意图

### FR-7 链路追踪

- FR-7.1 追踪列表（筛选、搜索）
- FR-7.2 追踪详情（查询、检索、生成、性能）

### FR-8 系统设置

- FR-8.1 LLM 配置
- FR-8.2 向量模型配置
- FR-8.3 检索参数配置

### FR-9 用户管理

- FR-9.1 用户列表
- FR-9.2 新建用户（用户名 3-20, 密码 6-128）
- FR-9.3 修改角色（user/admin）

### FR-10 其他

- FR-10.1 示例问题管理
- FR-10.2 关键词映射管理

---

## 2. 非功能需求

### NFR-1 性能

- 首屏加载 < 3 秒
- 路由切换 < 500ms
- SSE 首字节 < 2 秒
- Bundle 大小 < 500KB (gzipped)

### NFR-2 可用性

- 支持屏幕宽度 320px - 2560px
- 浏览器：Chrome 90+, Firefox 88+, Safari 14+
- 色彩对比度 ≥ 4.5:1（WCAG AA）

### NFR-3 安全

- Token 存储 localStorage
- Token 自动过期
- XSS 防护（React 转义）
- CSRF 防护（Token 认证）

### NFR-4 可维护性

- TypeScript 严格模式
- ESLint 无警告
- 代码注释清晰

---

## 3. 验收标准

### 功能验收

- 所有 FR 需求实现
- 核心流程无阻塞 bug

### 性能验收

- Lighthouse 评分 ≥ 85
- 首屏加载 < 3 秒
- 无明显卡顿

### 安全验收

- 无已知安全漏洞
- XSS/CSRF 防护有效

### 兼容性验收

- 主流浏览器正常运行
- 移动端体验良好

---

## 4. 优先级

| 优先级 | 功能 |
|--------|------|
| P0 | 登录、发送消息、会话管理、知识库管理 |
| P1 | 深度思考、引用来源、链路追踪、数据摄取 |
| P2 | 意图管理、示例问题、关键词映射 |
