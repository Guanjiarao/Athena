# Athena RAG Frontend 使用手册

> 版本：v1.0  
> 更新时间：2026-06-10

---

## 1. 快速开始

### 访问系统

打开浏览器访问：`http://your-domain.com`

### 登录

输入用户名和密码，点击登录。

---

## 2. 聊天功能

### 2.1 发送消息

1. 在输入框输入问题
2. 按 `Enter` 或点击发送按钮
3. AI 实时回复

**快捷键**：
- `Enter`：发送
- `Shift + Enter`：换行

### 2.2 深度思考模式

开启后 AI 先思考再回答，适合复杂问题。

点击输入框左侧的"深度思考"开关即可。

### 2.3 会话管理

**新建对话**：点击左侧"新建对话"

**切换会话**：点击左侧会话列表

**重命名**：悬停会话 → 点击编辑图标

**删除**：悬停会话 → 点击删除图标（需确认）

### 2.4 消息操作

- 复制：点击复制图标
- 反馈：点👍或👎
- 停止：点击停止按钮

---

## 3. 管理后台

### 3.1 进入后台

前提：账号为管理员（role: admin）

点击右上角用户菜单 → "管理后台"

### 3.2 仪表板

查看系统概况：知识库数、文档数、会话数、查询量

### 3.3 知识库管理

**创建知识库**：
1. 点击"新建知识库"
2. 填写名称、描述
3. 选择嵌入模型
4. 点击创建

**上传文档**：
1. 进入知识库详情
2. 点击"上传文档"
3. 选择文件（PDF/DOCX/TXT/MD/HTML）
4. 等待处理完成

**查看分块**：
1. 点击文档的"查看分块"
2. 查看文档切分后的 chunks

### 3.4 数据摄取

**批量导入文档**：
1. 进入"数据通道" → "流水线管理"
2. 选择目标知识库
3. 拖拽或选择多个文件
4. 配置参数（chunk_size, overlap）
5. 点击"开始摄取"

**参数说明**：
- Chunk Size：每块的 token 数（默认 512）
- Overlap：块间重叠 token 数（默认 50）

### 3.5 意图管理

**意图树**：查看意图层级结构

**意图列表**：表格形式管理意图

**编辑意图**：设置意图名称、父意图、触发关键词、响应策略

### 3.6 链路追踪

**查看追踪**：
1. 进入"链路追踪"
2. 查看 RAG 调用记录
3. 点击查看详情

**详情内容**：
- 查询信息
- 检索到的文档和相似度
- 使用的模型和 Prompt
- 耗时统计

### 3.7 系统设置

配置 LLM 参数、向量模型、检索参数等。

### 3.8 用户管理

**新建用户**：
1. 点击"新建用户"
2. 输入用户名、密码
3. 选择角色（user/admin）
4. 点击创建

**修改角色**：点击编辑 → 修改角色

### 3.9 示例问题

管理聊天欢迎页显示的示例问题。

### 3.10 关键词映射

配置查询词的同义词映射，如："怎么办" → "如何解决"

| 快捷键 | 功能 |
|--------|------|

## 5. 常见问题

**Q：忘记密码？**  
A：联系管理员重置

**Q：AI 回答不准确？**  
A：尝试更详细提问，或开启深度思考模式

**Q：文档上传失败？**  
A：检查文件格式（PDF/DOCX/TXT/MD/HTML）和大小（< 50MB）

**Q：流式响应中断？**  
A：刷新页面重试，或检查网络连接
