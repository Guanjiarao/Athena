# Athena RAG Frontend 功能设计

> 版本：v1.0  
> 更新时间：2026-06-10

---

## 1. 用户端功能

### 1.1 用户认证

- 登录（用户名 + 密码）
- 自动登录（Token 保持）
- 退出登录

### 1.2 智能对话

**基础对话**：
- 发送文本消息
- 实时流式响应
- Markdown 渲染
- 代码语法高亮

**深度思考模式**：
- AI 先思考再回答
- 显示思考过程
- 思考时间统计

**消息操作**：
- 复制消息
- 点赞/点踩反馈
- 停止生成
- 查看引用来源

### 1.3 会话管理

- 新建对话
- 切换会话
- 重命名会话
- 删除会话
- 会话列表（按时间排序）

---

## 2. 管理端功能

### 2.1 仪表板

- 知识库数量统计
- 文档总数
- 会话总数
- 查询量趋势图

### 2.2 知识库管理

**知识库操作**：
- 创建知识库（名称、描述、嵌入模型）
- 查看知识库列表
- 删除知识库

**文档管理**：
- 上传文档（PDF/DOCX/TXT/MD/HTML）
- 查看文档列表
- 删除文档
- 查看文档分块（chunks）

### 2.3 数据摄取

**流水线管理**：
- 批量上传文档
- 配置切分参数（chunk_size, overlap）
- 查看处理进度
- 查看任务列表

### 2.4 意图管理

**意图树**：
- 树形结构展示
- 层级关系可视化

**意图列表**：
- 表格形式管理
- 新建意图
- 编辑意图（名称、父意图、触发关键词、响应策略）
- 删除意图

### 2.5 链路追踪

**追踪列表**：
- 查看 RAG 调用记录
- 筛选（时间、状态、关键词）
- 查询时间、文本、耗时

**追踪详情**：
- 查询信息
- 检索结果（文档、相似度）
- 生成信息（模型、Prompt、回答）
- 性能统计

### 2.6 系统设置

- LLM 配置（模型、温度、Token 数）
- 向量模型配置
- 检索参数（Top K、相似度阈值）
- 提示词模板

### 2.7 用户管理

- 用户列表
- 新建用户
- 修改角色（user/admin）
- 删除用户

### 2.8 示例问题

- 管理欢迎页的示例问题
- 新建、编辑、删除
- 启用/禁用

### 2.9 关键词映射

- 配置查询词映射
- 同义词转换

---

## 3. 交互规范

### 3.1 响应式设计

- 手机端（< 640px）：单列布局
- 平板端（640-1024px）：自适应
- 桌面端（> 1024px）：完整功能

### 3.2 加载状态

- 按钮：显示加载动画
- 列表：骨架屏
- 长操作：进度条

### 3.3 错误提示

- Toast 通知
- 表单验证错误（字段下方）

### 3.4 确认对话框

- 删除操作必须确认
- 危险操作用红色按钮

---

## 4. 权限控制

- `user`：只能访问聊天功能
- `admin`：可访问所有功能

非管理员访问 `/admin/*` 自动跳转 `/chat`
