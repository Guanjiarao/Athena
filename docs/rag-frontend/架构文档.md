## 1. 系统架构

### 技术栈

- React 18.3.1 + TypeScript 5.5.4
- Vite 5.4.3（构建工具）
- React Router 6.26.2（路由）
- Zustand 4.5.5（状态管理）
- Tailwind CSS 3.4.10（样式）
- Axios 1.7.5（HTTP 客户端）

### 架构模式

```
Browser
  ↓
Pages (容器组件)
  ↓
Stores (Zustand 状态管理)
  ↓
Services (API 调用)
  ↓
Axios (HTTP/SSE)
  ↓
Backend API (:9090)
```

## 3. 核心模块

### 3.1 认证模块

**authStore**:
```typescript
{
  user: User | null
  token: string | null
  isAuthenticated: boolean
  login(username, password)
  logout()
  checkAuth()
}
```

**流程**：
1. 用户登录 → `POST /api/ragent/user/login`
2. 获取 Token → 存储到 localStorage
3. 设置 Axios 请求头 `Authorization`
4. 401 响应自动跳转登录页

### 3.2 聊天模块

**chatStore**:
```typescript
{
  sessions: Session[]
  messages: Message[]
  isStreaming: boolean
  deepThinkingEnabled: boolean
  sendMessage(content)
  cancelGeneration()
}
```

**流式响应**（SSE）:
```
GET /api/ragent/chat/stream?conversationId=xxx&query=xxx&deepThinking=true

Events:
  meta → {conversationId, taskId}
  thinking_delta → {delta: "思考内容"}
  delta → {delta: "回复内容"}
  completion → {messageId, title, references}
```

### 3.3 路由模块

**路由守卫**:
- `RequireAuth`: 验证登录
- `RequireAdmin`: 验证管理员
- `RedirectIfAuth`: 已登录重定向

**路由表**:
```
/ → 重定向
/login → 登录页
/chat → 聊天页
/chat/:sessionId → 对话页
/admin/* → 管理后台（10+ 页面）
```

## 4. 数据流

### 登录流程

```
用户输入 → authStore.login()
  ↓
authService.login() → POST /api/ragent/user/login
  ↓
获取 {userId, token, role}
  ↓
localStorage.setItem('token')
  ↓
axios.defaults.headers.Authorization = token
  ↓
跳转 /chat
```

### 聊天流程

```
用户输入 → chatStore.sendMessage()
  ↓
创建用户消息 + AI 占位消息
  ↓
EventSource('/api/ragent/chat/stream')
  ↓
监听事件 → 实时更新消息内容
  ↓
completion 事件 → 标记完成
```
