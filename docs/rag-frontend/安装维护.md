# Athena RAG Frontend 安装维护

> 版本：v1.0  
> 更新时间：2026-06-10

---

## 1. 环境要求

- Node.js >= 16.x（推荐 18.x）
- npm >= 8.x
- 浏览器：Chrome 90+ / Firefox 88+ / Safari 14+

---

## 2. 开发环境

### 2.1 安装依赖

```bash
cd athena_rag_front/rag-frontend/frontend
npm install
```

### 2.2 配置环境变量

创建 `.env`:
```env
VITE_API_BASE_URL=/api/ragent
VITE_APP_NAME=Athena RAG
```

### 2.3 启动开发服务器

```bash
npm run dev
```

访问 `http://localhost:5173`

**注意**：确保后端运行在 9090 端口

### 2.4 修改代理

如果后端端口不是 9090，修改 `vite.config.ts`:
```typescript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // 改为实际端口
      changeOrigin: true
    }
  }
}
```

## 3. 生产部署

### 3.1 构建

```bash
npm run build
```

输出到 `dist/` 目录

### 3.2 Nginx 部署

**复制文件**:
```bash
cp -r dist/* /var/www/athena-rag-frontend/
```

**Nginx 配置** (`/etc/nginx/sites-available/athena-rag`):
```nginx
server {
    listen 80;
    server_name your-domain.com;
    root /var/www/athena-rag-frontend;
    index index.html;

    # SPA 路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API 代理
    location /api/ragent {
        proxy_pass http://localhost:9090;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_read_timeout 300s;  # SSE 需要长连接
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

**启用配置**:
```bash
sudo ln -s /etc/nginx/sites-available/athena-rag /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl restart nginx
```

### 3.3 Docker 部署

**Dockerfile**:
```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

**构建运行**:
```bash
docker build -t athena-rag-frontend .
docker run -d -p 8080:80 athena-rag-frontend
```

## 4. 故障排查

### 问题 1：npm install 失败

**解决**:
```bash
npm cache clean --force
npm install --registry=https://registry.npmmirror.com
```

### 问题 2：端口被占用

**解决**:
```bash
# 查找进程
lsof -ti:5173 | xargs kill -9

# 或使用其他端口
npm run dev -- --port 5180
```

### 问题 3：API 404

**原因**：后端未启动或代理配置错误

**解决**:
```bash
# 测试后端
curl http://localhost:9090/api/ragent/health

# 重启前端
npm run dev
```

### 问题 4：白屏或刷新 404

**原因**：Nginx 未配置 SPA 路由

**解决**：确保 Nginx 配置包含：
```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

### 问题 5：SSE 连接中断

**解决**：增加 Nginx 超时：
```nginx
proxy_read_timeout 300s;
proxy_connect_timeout 75s;
```

## 6. 安全

### Nginx 安全配置

```nginx
# 隐藏版本
server_tokens off;

# 安全头
add_header X-Frame-Options "SAMEORIGIN";
add_header X-XSS-Protection "1; mode=block";
add_header X-Content-Type-Options "nosniff";
```

### HTTPS 配置

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx

# 获取证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo certbot renew --dry-run
```
