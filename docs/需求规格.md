# 需求规格

本文档描述 Athena 双端系统的需求范围、功能要求和非功能要求。

## 1. 项目目标

建立一个面向女性健康场景的双端系统，满足：

- 内容生产和审核管理
- 女性健康知识分发
- 周期与健康记录
- AI 辅助问答
- 隐私保护和健康分析

## 2. 范围说明

### 2.1 包含范围

- Web 管理后台
- Android App 客户端
- 内容审核与发布协同
- 健康知识内容浏览
- 社区内容浏览与发布
- AI 问答与辅助分析
- 周期、记录和隐私相关能力

### 2.2 不包含范围

- 后端服务实现细节
- 第三方云服务底层配置
- 运营策略和审核规则的最终裁定

## 3. 功能需求

### 3.1 Web 管理端需求

#### 3.1.1 登录需求

- 系统应支持用户登录。
- 系统应根据角色区分管理员和发布者。
- 未登录用户不得访问受保护页面。

#### 3.1.2 审核需求

- 管理员应能查看待审内容。
- 管理员应能查看内容详情。
- 管理员应能删除违规内容。
- 管理员应能按类型和模块筛选内容。

#### 3.1.3 发布需求

- 发布者应能发布文章。
- 发布者应能发布视频。
- 发布内容提交后应进入后续流程。

#### 3.1.4 内容管理需求

- 管理员应能管理已发布内容。
- 管理员应能查看内容状态、标题、封面和正文。
- 管理员应能删除不合规内容。

### 3.2 App 端需求

#### 3.2.1 登录注册需求

- 系统应支持注册和登录。
- 登录态应可本地保存。
- 登录后应展示主导航。

#### 3.2.2 知识浏览需求

- 系统应支持分类浏览健康知识。
- 系统应支持文章详情查看。
- 系统应支持按人群和主题分组。

#### 3.2.3 社区广场需求

- 系统应支持浏览图文和视频内容。
- 系统应支持内容详情、评论和互动。
- 系统应支持发布内容入口。

#### 3.2.4 AI 辅助需求

- 系统应支持用户输入问题。
- 系统应支持返回 AI 辅助回答。
- 系统应支持与知识内容关联展示。

#### 3.2.5 记录与监测需求

- 系统应支持周期记录。
- 系统应支持排卵或生理相关提醒。
- 系统应支持健康记录和分析结果展示。

#### 3.2.6 隐私需求

- 系统应支持对敏感图像进行本地脱敏。
- 系统应支持在上传前执行必要的隐私处理。
- 系统应尽量减少敏感信息明文暴露。

## 4. 非功能需求

### 4.1 可用性

- 页面与功能入口应清晰易懂。
- 常用操作应在 3 次点击内可达。

### 4.2 性能

- 列表页应支持分页或分批加载。
- 图片和视频应按需加载。
- AI 和上传请求应有明确的加载反馈。

### 4.3 可靠性

- 网络异常时应提示错误原因。
- 接口返回异常时应支持用户重试。
- 登录状态失效时应可重新登录恢复。

### 4.4 安全性

- 鉴权 token 不应明文暴露在 UI 中。
- 敏感数据处理应遵循最小暴露原则。
- 涉及隐私内容的功能应有明确提示和限制。

### 4.5 可维护性

- 页面、模块和接口应分层组织。
- 关键配置应集中管理。
- 新增功能应同步更新文档。

## 5. 约束条件

- Web 端基于 Vite + React + TypeScript。
- Android 端基于原生 Android 项目。
- App 需兼容项目中定义的最低 Android 版本。
- 依赖第三方 SDK 时需保持版本兼容和网络可用性。

## 6. 验收要点

### 6.1 Web 端

- 登录后可根据角色进入正确页面。
- 审核、管理和发布功能可正常使用。
- 受保护页面在未登录时不可直接访问。

### 6.2 App 端

- App 可正常启动并显示主导航。
- 知识、广场、AI、记录、我的模块可正常切换。
- 登录后状态可持久化。
- 图片、视频、记录和隐私相关功能可正常打开。



## 5. RAG 前端需求

### 5.1 功能需求

**FR-RAG-1 用户认证**：
- FR-RAG-1.1 用户登录（用户名 + 密码）
- FR-RAG-1.2 Token 自动登录
- FR-RAG-1.3 退出登录

**FR-RAG-2 智能对话**：
- FR-RAG-2.1 发送文本消息（1-2000 字符）
- FR-RAG-2.2 实时流式响应（SSE）
- FR-RAG-2.3 深度思考模式
- FR-RAG-2.4 停止生成
- FR-RAG-2.5 消息反馈（点赞/点踩）

**FR-RAG-3 会话管理**：
- FR-RAG-3.1 获取会话列表
- FR-RAG-3.2 创建新会话
- FR-RAG-3.3 切换会话
- FR-RAG-3.4 重命名会话（1-50 字符）
- FR-RAG-3.5 删除会话（需确认）

**FR-RAG-4 知识库管理**：
- FR-RAG-4.1 创建知识库
- FR-RAG-4.2 上传文档（PDF/DOCX/TXT/MD/HTML, < 50MB）
- FR-RAG-4.3 查看文档列表
- FR-RAG-4.4 查看文档分块
- FR-RAG-4.5 删除知识库/文档

**FR-RAG-5 数据摄取**：
- FR-RAG-5.1 批量上传文档
- FR-RAG-5.2 配置参数（chunk_size: 256-2048, overlap: 0-200）

**FR-RAG-6 链路追踪**：
- FR-RAG-6.1 追踪列表（筛选、搜索）
- FR-RAG-6.2 追踪详情（查询、检索、生成、性能）

**FR-RAG-7 用户管理**：
- FR-RAG-7.1 用户列表
- FR-RAG-7.2 新建用户（用户名 3-20, 密码 6-128）
- FR-RAG-7.3 修改角色（user/admin）

### 5.2 非功能需求

**NFR-RAG-1 性能**：
- 首屏加载 < 3 秒
- 路由切换 < 500ms
- Bundle 大小 < 500KB (gzipped)

**NFR-RAG-2 可用性**：
- 支持屏幕宽度 320px - 2560px
- 浏览器：Chrome 90+, Firefox 88+, Safari 14+

**NFR-RAG-3 安全**：
- Token 存储 localStorage
- XSS 防护（React 转义）
- CSRF 防护（Token 认证）
