## 三、面试到底考什么（面经提炼）

### 硬性能力拆解

| 维度 | 具体内容 | 占比权重 |
|:----|:---------|:-------:|
| **基础工程能力** | Python/Java、FastAPI/SpringBoot、并发异步、HTTP/RESTful、Docker、Git | ⭐⭐⭐⭐⭐ |
| **大模型核心理解** | Transformer原理（Attention）、Prompt工程（Zero-shot/CoT）、Token/Temperature、Function Calling、工具调用、长上下文 | ⭐⭐⭐⭐⭐ |
| **Agent/RAG实战** | ReAct模式、工具调用流程、RAG实现、Embedding、向量数据库、多轮对话 | ⭐⭐⭐⭐⭐ **（拷打重点）** |
| **系统设计** | 日志、Prompt版本管理、幻觉控制、结果校验、权限、灰度 | ⭐⭐⭐⭐（亮点） |

### 面试高频题（来自面经整理）

**Agent方向：**
1. 什么是Agent？Agent和普通LLM调用有什么区别？
2. ReAct模式的工作原理是什么？讲一下"推理-行动"循环
3. 如何设计多Agent协作系统？
4. 工具调用（Function Calling）怎么实现？
5. Agent的Memory机制怎么设计？短期/长期记忆如何区分？
6. 如何防止Agent陷入死循环？

**RAG方向：**
1. RAG的完整流程是什么？
2. Embedding是怎么工作的？
3. 如何做Chunk拆分？不同策略的优缺点？
4. 检索结果怎么做Rerank？
5. 如何提升RAG的召回率？
6. 用户query怎么Rewrite？

**工程方向：**
1. 长上下文问题怎么处理？
2. 如何控制LLM的幻觉？
3. Prompt怎么版本管理？
4. SSE流式输出怎么实现？
5. 如何做Token成本监控？
