# 使用手册

本文档说明 Athena 双端系统的日常使用方式，覆盖网站前端和 Android App 两部分。

## 1. 系统组成

- 网站前端 `admin_web_front`
- Android App `athena_app_front`

两端共同服务于内容生产、内容分发和女性健康场景使用。

## 2. 网站前端使用说明

### 2.1 登录

1. 打开管理后台登录页。
2. 输入账号信息完成登录。
3. 系统会根据角色进入不同首页。

### 2.2 角色说明

- `admin`：管理员，主要负责审核与内容管理。
- `kol`：发布者，主要负责内容发布。

### 2.3 审核功能

管理员登录后可进入审核页面，对待审内容进行查看、审核和状态处理。

常见操作包括：

- 查看内容列表
- 查看内容详情
- 根据规则筛选内容
- 删除不合规内容

### 2.4 内容管理

管理员可在内容管理页面查看已发布内容，支持：

- 按模块筛选
- 按内容类型筛选
- 查看详情
- 删除内容

### 2.5 内容发布

发布者可进入发布页面，按内容类型进行操作：

- 发布文章
- 发布视频

提交后内容会进入后台流程，由管理员继续处理。

### 2.6 设置

设置页面用于查看和调整系统相关配置，具体可用项取决于后端接口和当前账号权限。

## 3. App 使用说明

### 3.1 登录与注册

1. 启动 App 后进入登录或个人页入口。
2. 新用户可先完成注册。
3. 登录成功后，底部导航会显示主功能区。

### 3.2 首页与底部导航

App 主导航包含以下模块：

- `知识`
- `广场`
- `AI`
- `记录`
- `我的`

### 3.3 知识模块

知识模块用于浏览健康科普内容，按不同主题分类查看。

支持内容类型包括：

- 月经相关
- 备孕相关
- 避孕相关
- 青春期相关
- 成熟阶段相关
- 55+ 相关
- 亲子/家庭相关
- 皮肤护理相关

### 3.4 广场模块

广场模块用于查看社区动态、图文内容和视频内容，也支持发布入口。

常见操作：

- 浏览内容列表
- 打开内容详情
- 评论互动
- 发布图文或视频

### 3.5 AI 模块

AI 模块提供智能问答、科普检索、健康咨询辅助等能力。

可用于：

- 文字问答
- 问题检索
- 参考内容展示

### 3.6 记录模块

记录模块用于经期、排卵、健康记录等数据管理。

可进行：

- 周期记录
- 生理期跟踪
- 健康事件记录
- 相关提醒和分析

### 3.7 我的模块

个人中心用于管理用户资料与隐私相关功能，例如：

- 编辑资料
- 查看关注/粉丝
- 隐私保护
- 私密相册
- 与健康设备或分析功能相关入口

## 4. 使用建议

- 首次使用前先确认网络正常。
- 涉及图片上传、视频播放、AI 分析时，请确保权限已授予。
- 若出现登录态丢失，可重新登录刷新本地 token。
- 若内容无法加载，优先检查接口地址、后端服务状态和网络连通性。
