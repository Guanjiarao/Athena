# Athena 系统使用手册

本文档说明 Athena 项目各子系统的日常使用方式，包含三个独立模块：
- **网站前端**（`admin_web_front`）— 内容审核、发布与管理后台
- **App 端**（`athena_app_front`）— 女性健康知识浏览、社区互动与健康记录
- **RAG 前端**（`athena_rag_front`）— 智能检索对话系统，提供 AI 驱动的知识问答服务

三者面向不同用户角色和使用场景，以下按模块分别说明。

---

# 第一部分：网站端与 App 端

## 1. 系统组成

- 网站前端 `admin_web_front`
- Android App `athena_app_front`

两端共同服务于内容生产、内容分发和女性健康场景使用。

## 2. 网站前端使用说明

### 2.1 登录

1. 打开管理后台登录页。
2. 输入账号信息完成登录。
3. 系统会根据角色进入不同首页。

### 2.2 角色说明

- `admin`：管理员，主要负责审核与内容管理。
- `kol`：发布者，主要负责内容发布。

### 2.3 审核功能

管理员登录后可进入审核页面，对待审内容进行查看、审核和状态处理。

常见操作包括：

- 查看内容列表
- 查看内容详情
- 根据规则筛选内容
- 删除不合规内容

### 2.4 内容管理

管理员可在内容管理页面查看已发布内容，支持：

- 按模块筛选
- 按内容类型筛选
- 查看详情
- 删除内容

### 2.5 内容发布

发布者可进入发布页面，按内容类型进行操作：

- 发布文章
- 发布视频

提交后内容会进入后台流程，由管理员继续处理。

### 2.6 设置

设置页面用于查看和调整系统相关配置，具体可用项取决于后端接口和当前账号权限。

## 3. App 使用说明

### 3.1 登录与注册

1. 启动 App 后进入登录或个人页入口。
2. 新用户可先完成注册。
3. 登录成功后，底部导航会显示主功能区。

### 3.2 首页与底部导航

App 主导航包含以下模块：

- `知识`
- `广场`
- `AI`
- `记录`
- `我的`

### 3.3 知识模块

知识模块用于浏览健康科普内容，按不同主题分类查看。

支持内容类型包括：

- 月经相关
- 备孕相关
- 避孕相关
- 青春期相关
- 成熟阶段相关
- 55+ 相关
- 亲子/家庭相关
- 皮肤护理相关

### 3.4 广场模块

广场模块用于查看社区动态、图文内容和视频内容，也支持发布入口。

常见操作：

- 浏览内容列表
- 打开内容详情
- 评论互动
- 发布图文或视频

### 3.5 AI 模块

AI 模块提供智能问答、科普检索、健康咨询辅助等能力。

可用于：

- 文字问答
- 问题检索
- 参考内容展示

### 3.6 记录模块

记录模块用于经期、排卵、健康记录等数据管理。

可进行：

- 周期记录
- 生理期跟踪
- 健康事件记录
- 相关提醒和分析

### 3.7 我的模块

个人中心用于管理用户资料与隐私相关功能，例如：

- 编辑资料
- 查看关注/粉丝
- 隐私保护
- 私密相册
- 与健康设备或分析功能相关入口

## 4. 使用建议

- 首次使用前先确认网络正常。
- 涉及图片上传、视频播放、AI 分析时，请确保权限已授予。
- 若出现登录态丢失，可重新登录刷新本地 token。
- 若内容无法加载，优先检查接口地址、后端服务状态和网络连通性。

# 第二部分：RAG 智能检索对话系统

## 5. RAG 系统概述

Athena RAG（Retrieval-Augmented Generation）是 Athena 项目中的智能检索对话系统，面向**女性健康知识传播**场景，提供 AI 驱动的知识问答服务。系统由前端 Web 应用和后端 RAG 引擎组成，支持用户智能对话与管理后台运维两大核心场景。

### 5.1 系统组成

| 模块 | 说明 |
|------|------|
| **用户端** | 智能对话、会话管理、深度思考、示例问题引导 |
| **管理端** | 知识库管理、数据摄取、意图管理、链路追踪、系统设置、用户管理 |

### 5.2 用户角色

| 角色 | 权限范围 |
|------|----------|
| **普通用户（user）** | 登录后进入聊天页，仅可进行智能对话与会话管理 |
| **管理员（admin）** | 除对话功能外，可访问管理后台全部功能 |

## 6. 登录与认证

### 6.1 登录入口

访问系统后，自动跳转至登录页面 `/login`。

![登录页面](images/rag-frontend/01-login.png)

### 6.2 登录流程

1. 在登录页输入**用户名**和**密码**
2. 勾选「记住我」可保持登录状态（默认已勾选）
3. 点击「登录」按钮或按 Enter 提交
4. 系统验证身份后，根据角色自动跳转：
   - `user` 角色 → **聊天页** (`/chat`)
   - `admin` 角色 → 同样进入聊天页，但侧边栏显示「管理后台」入口

> 账号由管理员在后台初始化创建。新用户请联系管理员获取账号。

## 7. 用户端功能

### 7.1 聊天主界面

登录后进入聊天主界面，页面采用左右分栏布局：

![聊天主界面](images/rag-frontend/02-chat.png)

**左侧边栏**包含：
- Athena 品牌标识（「Athena 科普助手 小雅」）
- 「新建对话」按钮 — 从空白开始新会话
- 「管理后台」按钮 — 仅 admin 角色可见，跳转管理后台
- 搜索对话 — 支持快捷键 `Ctrl/Cmd + K` 快速搜索
- **会话列表** — 按时间分组（今天 / 7天内 / 30天内），每条会话显示标题和操作菜单

**右侧主区域**包含：
- 顶部 Banner — 显示当前会话标题（新会话显示「新对话」）
- **欢迎区** — 未开始对话时展示：
  - 品牌标语：「女性健康科普系统 — 把问题变成清晰答案」
  - 三个快捷示例问题卡片（月经周期 / 备孕指导 / 健康咨询）
- **输入区** — 底部固定，包含文本输入框、深度思考开关、发送按钮
- 键盘提示 — `Enter 发送 · Shift + Enter 换行`

### 7.2 智能对话

点击历史会话或示例问题卡片即可进入对话视图：

![对话详情](images/rag-frontend/13-conversation.png)

**发送消息**：
1. 在底部输入框输入问题（1-2000 字符）
2. 按 `Enter` 发送，`Shift + Enter` 换行
3. 系统流式返回 AI 回答，支持 Markdown 渲染和代码高亮

**深度思考模式**：
- 点击输入框右侧「深度思考」开关启用
- AI 会先展示推理过程，再给出最终回答
- 适用于复杂问题或需要多步分析的场景

**消息操作**：
- **复制** — 复制消息内容
- **点赞/点踩** — 对回答进行质量反馈
- **停止生成** — 点击停止按钮中断流式输出
- **查看引用** — 如回答基于知识库文档，可点击引用链接查看来源

### 7.3 会话管理

**新建会话**：点击侧边栏「新建对话」按钮，创建一个空白会话。

**切换会话**：点击侧边栏中任意会话卡片，切换到对应对话记录。

**重命名会话**：
1. 鼠标悬停在会话卡片上
2. 点击右侧「···」菜单按钮
3. 选择「重命名」
4. 输入新名称（1-50 字符）后保存

**删除会话**：
1. 鼠标悬停在会话卡片上
2. 点击右侧「···」菜单按钮
3. 选择「删除」
4. 确认删除操作（删除后不可恢复，同时清空所有消息记录）

**搜索会话**：点击侧边栏搜索框（或按 `Ctrl/Cmd + K`），输入关键词快速定位历史会话。

> 会话列表按更新时间倒序排列，自动按「今天 / 7天内 / 30天内」分组。

### 7.4 示例问题

新会话或空会话时，主区域展示三个快捷示例问题卡片：

| 卡片 | 主题 | 推荐问法示例 |
|------|------|-------------|
| 月经周期 | 了解月经周期的变化与健康 | 「我想了解月经周期相关的知识」 |
| 备孕指导 | 获取科学的备孕建议 | 「我想咨询备孕相关的建议」 |
| 健康咨询 | 女性健康问题解答 | 「我有一些女性健康方面的问题想咨询」 |

点击卡片可直接发起对应主题的对话。

## 8. 管理端功能

管理员在聊天页点击侧边栏「管理后台」按钮，进入管理后台。

### 8.1 仪表板

**入口**：`/admin/dashboard`

![仪表板](images/rag-frontend/03-dashboard.png)

仪表板展示系统核心运营数据概览：

- **知识库数量** — 当前系统知识库总数
- **文档总数** — 已上传并处理的文档总量
- **会话总数** — 用户创建的对话会话总数
- **查询量趋势图** — 近 7 天查询量变化折线图

> 仪表板数据为只读展示，用于快速了解系统运行状态。

### 8.2 知识库管理

**入口**：`/admin/knowledge`

![知识库管理](images/rag-frontend/04-knowledge.png)

知识库是 RAG 系统的核心数据资产。该页面以卡片形式展示所有知识库。

**创建知识库**：
1. 点击「创建知识库」按钮
2. 填写**名称**（必填）、**描述**（选填）
3. 选择**嵌入模型**（如 `text-embedding-3-small`）
4. 提交创建

**每个知识库卡片展示**：名称、描述、文档数量、创建时间。

**操作入口**：
- 点击知识库卡片 → 进入文档管理页（`/admin/knowledge/:kbId`）
- 点击卡片右上角「删除」 → 删除知识库（同时删除所有关联文档，不可恢复）

**文档管理**（知识库详情页）：
- 查看文档列表（文件名、大小、上传时间）
- 上传新文档（支持 PDF / DOCX / TXT / MD / HTML，单文件 < 50MB）
- 删除文档
- 查看文档分块（`/admin/knowledge/:kbId/docs/:docId`）

### 8.3 数据摄取

**入口**：`/admin/ingestion`

![数据摄取](images/rag-frontend/05-ingestion.png)

数据通道为 Athena 笔记建立了一套完整的流水线，文档自动入库。点击编辑可以修改流水线配置。

**批量上传流程**：
1. 选择目标知识库
2. 拖拽或点击上传多个文件（支持多选）
3. 配置切分参数：
   - **chunk_size**：分块大小（256-2048 字符，默认 512）
   - **overlap**：相邻块重叠字符数（0-200，默认 50）
4. 点击「开始处理」
5. 查看实时处理进度状态

**页面 Tab 切换**：
- **Pipelines** — 查看所有数据处理管道（任务列表），显示文件名、状态、进度、时间
- **Documents** — 查看已处理文档记录

### 8.4 意图管理（树形视图）

**入口**：`/admin/intent-tree`

![意图树](images/rag-frontend/06-intent-tree.png)

以**树形结构**展示意图层级关系，直观呈现意图之间的父子关联。

**支持操作**：
- 展开 / 折叠节点
- 点击节点查看意图详情
- 新建子意图（右键或工具栏按钮）
- 编辑 / 删除意图

> 意图管理用于定义用户提问的识别规则和响应策略，是提升 RAG 问答准确度的关键配置。

### 8.5 意图管理（列表视图）

**入口**：`/admin/intent-list`

![意图列表](images/rag-frontend/07-intent-list.png)

以**表格列表**形式管理所有意图配置，适合批量操作和条件筛选。

**支持操作**：
- 查看所有意图（表格列：名称、父意图、触发关键词、状态、操作）
- **新建意图** — 填写名称、父意图、触发关键词、响应策略
- **编辑意图** — 点击编辑按钮进入编辑页（`/admin/intent-list/:id/edit`）
- **删除意图** — 移除不再需要的意图

> 树形视图和列表视图数据互通，可根据操作习惯自由切换。

### 8.6 链路追踪

**入口**：`/admin/traces`

![链路追踪](images/rag-frontend/08-traces.png)

链路追踪页面用于**监控和调试 RAG 调用全链路**，是问题排查和性能优化的核心工具。

**追踪列表**：
- 显示所有 RAG 调用记录（表格列：查询时间、查询文本、耗时、状态）
- 支持筛选：时间范围、状态、关键词搜索
- 每条记录可点击进入详情

**追踪详情页**（`/admin/traces/:traceId`）展示完整调用链路：

| 信息分类 | 内容 |
|----------|------|
| 查询信息 | 原始问题文本、查询时间 |
| 检索结果 | 匹配到的文档片段、相似度分数 |
| 生成信息 | 使用的 LLM 模型、Prompt 模板、最终生成的回答 |
| 性能统计 | 各阶段耗时（检索/生成/总耗时） |

### 8.7 系统设置

**入口**：`/admin/settings`

![系统设置](images/rag-frontend/09-settings.png)

系统设置页面集中管理 RAG 引擎的核心配置参数。

**LLM 配置**：
- 选择大语言模型（如 GPT-4、Claude 等）
- 设置温度参数（0.0 - 1.0，越低越确定）
- 设置最大 Token 数

**向量模型配置**：
- 选择嵌入模型（如 `text-embedding-3-small`）
- 配置向量维度

**检索参数**：
- **Top K** — 每次查询返回的相关文档数量（1-20）
- **相似度阈值** — 过滤低相关性结果（0.0 - 1.0）

**提示词模板**：
- 编辑系统 Prompt
- 配置回答格式要求（如输出结构、语气风格等）

> 修改配置后点击「保存」生效。建议修改前记录当前值，以便出问题时回滚。

### 8.8 示例问题管理

**入口**：`/admin/sample-questions`

![示例问题管理](images/rag-frontend/10-sample-questions.png)

管理聊天页「试试这些开场」区域的示例问题卡片。

**支持操作**：
- 查看现有示例问题列表
- **新建示例问题** — 设置标题、描述、推荐问法
- **编辑** — 修改问题文本和配置
- **启用/禁用** — 控制是否在用户端展示
- **删除** — 移除示例问题

> 示例问题是用户首次进入系统时的引导入口，建议定期更新以反映热门话题和最新知识库内容。

### 8.9 关键词映射管理

**入口**：`/admin/mappings`

![关键词映射](images/rag-frontend/11-mappings.png)

配置查询词映射和同义词转换规则，用于**优化检索命中率**。

**典型场景**：
- 「大姨妈」→ 映射为「月经」查询知识库
- 「备孕」→ 映射为「孕前准备」查询
- 英中术语转换（如 `PCOS` → `多囊卵巢综合征`）

**支持操作**：
- 添加映射规则（源关键词 → 目标关键词）
- 测试映射效果
- 编辑 / 删除映射

### 8.10 用户管理

**入口**：`/admin/users`

![用户管理](images/rag-frontend/12-users.png)

管理系统的所有用户账号。

**用户列表**：以表格展示所有用户（用户名、角色、创建时间、状态）。

**新建用户**：
1. 点击「新建用户」
2. 填写用户名（3-20 字符）
3. 设置密码（6-128 字符）
4. 选择角色（`user` / `admin`）
5. 提交创建

**修改角色**：
1. 点击用户行的「编辑」按钮
2. 修改角色选择
3. 保存更改

**删除用户**：
1. 点击用户行的「删除」按钮
2. 确认删除操作

> 删除用户不可恢复。删除前请确认该用户无活跃会话或重要数据。

## 9. 常见问题

### 9.1 无法连接后端

**现象**：页面提示「网络错误」或空白页面

**排查步骤**：
1. 确认后端 Spring Boot 服务正在运行（默认端口 9090）
2. 检查 Vite 代理配置（`vite.config.ts` 中 proxy 指向 `http://localhost:9090`）
3. 重启前端开发服务器：`npm run dev`

### 9.2 SSE 流式输出中断

**现象**：AI 回答输出到一半停止

**排查步骤**：
1. 检查网络连接是否稳定
2. 若部署了 Nginx，确认 `proxy_read_timeout` 足够长（建议 300s+）
3. 点击「停止」按钮后重新发送消息

### 9.3 文档上传失败

**现象**：上传文件后提示错误

**排查步骤**：
1. 检查文件大小是否超过 50MB
2. 确认文件格式为 PDF / DOCX / TXT / MD / HTML
3. 检查后端存储服务是否正常
4. 查看浏览器控制台（F12）错误详情

### 9.4 Token 过期

**现象**：操作时提示「未授权」或跳转登录页

**解决方法**：
1. 退出登录
2. 使用账号密码重新登录
3. 若频繁过期，联系管理员检查后端 Token 有效期配置

### 9.5 AI 回答不符合预期

**建议**：
- 使用**完整、清晰、具体**的提问方式
- 说明问题背景（如年龄阶段、持续时间、已采取措施）
- 启用「深度思考」模式处理复杂问题
- 通过链路追踪页面查看实际检索到的文档，判断是否需要补充知识库内容
- 检查意图树和关键词映射配置是否覆盖当前问法

## 10. 操作建议

1. **定期备份知识库** — 重要知识库数据应定期导出备份
2. **监控链路追踪** — 日常关注追踪页面，及时发现检索质量下降或性能瓶颈
3. **优化检索参数** — 根据实际使用效果，调整 Top K 和相似度阈值
4. **维护意图树** — 随着用户提问模式变化，及时更新意图配置和关键词映射
5. **清理无效会话** — 定期删除测试会话和过期会话，节省存储空间
6. **示例问题更新** — 定期刷新聊天页示例问题，引导用户了解最新功能
